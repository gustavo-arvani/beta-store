# 🛍️ BETA Store

**BETA Store** é uma aplicação de e-commerce desenvolvida com **React e Vite**, criada como projeto prático para aplicar e consolidar conhecimentos de desenvolvimento Front-end.

A aplicação utiliza dados de uma API externa para exibir os produtos e permite ao usuário navegar pelas categorias, visualizar detalhes dos produtos e gerenciar um carrinho de compras.

## ✨ Funcionalidades

* 🏠 Página inicial com categorias e produtos
* 🛍️ Listagem de produtos
* 🔎 Filtro de produtos por categoria
* 📦 Página de detalhes dos produtos
* 🛒 Adição e remoção de produtos do carrinho
* ➕ Controle de quantidade dos produtos
* 💰 Cálculo automático de subtotais e valor total
* 💾 Persistência do carrinho utilizando LocalStorage
* 🔔 Notificações e feedback visual com React Toastify
* 📱 Layout responsivo para diferentes tamanhos de tela

## 🧰 Tecnologias

* React
* JavaScript
* Vite
* HTML5
* CSS3
* React Router DOM
* React Toastify
* Fake Store API
* LocalStorage

## 🎯 Objetivo

O projeto foi desenvolvido com foco em **componentização, gerenciamento de estado, consumo de APIs, navegação entre páginas, persistência de dados e desenvolvimento responsivo**.

Além da implementação das funcionalidades, também trabalhei na construção da interface e na experiência de navegação, buscando deixar a aplicação simples, organizada e agradável de utilizar.
